# Support

Use [GitHub Issues](https://github.com/timaa130704/LinkiGram/issues) for reproducible bugs and feature proposals. Include the LinkiGram version, device model, Android version and exact reproduction steps.

Reports and questions are accepted in English, Russian and Chinese.

Use [GitHub Discussions](https://github.com/timaa130704/LinkiGram/discussions) for development questions and general project discussion.

Do not publish credentials, signing material, phone numbers, private messages or unredacted logs. Security vulnerabilities must be reported through a [private security advisory](https://github.com/timaa130704/LinkiGram/security/advisories/new).
