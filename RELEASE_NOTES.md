# LinkiGram v2.6.1

## Новое

- **Ghost mode по чатам:** исключения для отдельных диалогов, отдельное управление скрытием записи голосовых сообщений и индикатор активных настроек в заголовке чата.
- **Material 3:** расширено оформление общих элементов интерфейса, списков и экранов настроек.
- **Навигация и наборы иконок:** исправлено взаимодействие стеклянного эффекта с закреплённой нижней панелью и обновлением иконок.
- **Бета-обновления:** добавлен необязательный канал предварительных версий с выбором подходящей версии.

## Исправления

- Исправлены ошибки отображения стиля Material 3 и обработки переключения эффектов.
- Улучшено переключение наборов иконок в уже открытых экранах.

Скачать APK можно во вложениях релиза. Обновление устанавливается поверх предыдущей версии.

# LinkiGram v2.21

## 🔄 Прокси в фоне + уведомления всегда приходят

- **Прокси теперь работает в фоне.** При уходе приложения в фон (и при выключенном экране) соединение через прокси больше не «засыпает» — обновления и уведомления приходят постоянно, даже если пуш-канал (FCM) недоступен или ненадёжен.
- **Фоновый сервис уведомлений включается автоматически** при активном прокси: на Android 8–14 он работает как foreground service (устойчив к Doze и агрессивным энергосберегающим режимам), после убийства процесса сервис самовосстанавливается.
- При включённом прокси в статус-баре появляется постоянная иконка «LinkiGram» — это гарантирует стабильную доставку уведомлений в фоне. При выключенном прокси поведение приложения не меняется.
- Незначительно повышается расход батареи при включённом прокси (соединение держится постоянно).

## 📌 Примечание
Включает все функции и оптимизации из 2.2 (Ghost mode, точный last seen).

## 📥 Установка
Скачайте `LinkiGram-2.21.apk` ниже. Ставится поверх 2.x без потери данных (только ARM64).
