# LinkiGram v2.11

## ⚡ Оптимизация под слабые устройства

- **Анимация текста (TextAnim) выключена по умолчанию.** Это была самая тяжёлая фича: хуки на каждое поле ввода и бесконечные перерисовки 60 fps даже в простое. Теперь плавнее и меньше расход батареи. Включить можно обратно: Настройки → Анимация текста.
- **Убраны лаги при вводе текста**: больше нет копирования всего текста поля на каждый кадр и холостых перерисовок без активных анимаций.
- **Список чатов**: LaTeX-обработка больше не копирует весь текст сообщения при отрисовке каждой ячейки.

## 📦 Размер APK

- **Standalone APK теперь ~120 МБ вместо сотен мегабайт**: включены R8-минификация и сжатие ресурсов по умолчанию, отладочные символы NDK убраны из APK (SYMBOL_TABLE вместо FULL).
- Отключить сжатие при сборке можно флагом `-PngNoCompactStandalone`.

## 🛠 Сборка

- Gradle-демон, параллельная сборка и инкрементальные ресурсы включены — локальная сборка заметно быстрее.
- CI: починен шаг Setup Android SDK (Google удалил пакет `tools`), добавлены отмена устаревших запусков и таймаут.

## 📥 Установка

Скачайте `LinkiGram-2.11.apk` ниже. Ставится поверх 2.x без потери данных (только ARM64; для ARMv7 собирайте из исходников с `-PngArm64Only=false`).
