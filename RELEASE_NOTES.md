# LinkiGram v2.2

## 👻 Ghost mode + точный last seen

- **Новое: «Показывать точный “был(а) в сети”»** (включено по умолчанию). Вместо размытого «был(а) недавно» показывает точное время из локального кэша: «был(а) сегодня в 14:32 (по кэшу)». Работает для контактов, чей last seen был виден ранее. Настройки LinkiGram → Ghost mode.
- Подтверждено, что Ghost mode — настоящий: статусы «в сети», «печатает» и галочки прочтения не отправляются на сервер вовсе.

## 📌 Примечание
Включает все оптимизации производительности и размера APK из 2.11.

## 📥 Установка
Скачайте `LinkiGram-2.2.apk` ниже. Ставится поверх 2.x без потери данных (только ARM64).
