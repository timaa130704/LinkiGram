# CLAUDE.md

Проектные заметки лежат в [AGENTS.md](AGENTS.md) — прочитай его перед работой.

Коротко о главном:

- Это форк Telegram Android (`timaa130704/LinkiGram`), база **12.10.5**, пакет
  `app.linkigram.messenger`.
- Своё лежит в `app.nimarkogram.messenger`, Python-плагины — в
  `TMessagesProj/src/main/python`.
- **Релизная сборка ломает всё через R8.** Правило
  `-keep class org.telegram.** { *; }` обязательно: плагины ищут классы по
  исходным именам, и без него `org.telegram.ui.MainTabsActivity` переименовывается,
  а плагин грузится вообще без интерфейса.
- **Перед каждым пушем проверяй:** баланс скобок в изменённом Java, валидность XML,
  и все внешние символы, которые использует новый код. Эти три проверки ловят
  почти все ошибки компиляции — сборка стоит 25 минут.
- **Диагностируй по `logcat` с телефона, а не рассуждениями.** Каждая реальная
  причина в этом проекте нашлась в логе; ни одну не угадали.
