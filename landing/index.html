Прокси в фоне —
уведомления всегда приходят

При уходе приложения в фон соединение через прокси больше не засыпает. Обновления и уведомления идут постоянно, даже если push-канал FCM недоступен. Фоновый сервис самовосстанавливается после закрытия процесса.

  • Уведомления не зависят от FCM
  • Foreground-сервис на Android 8–14
  • Иконка LinkiGram в статус-баре при активном прокси

FAQ

Частые вопросы

Это официальный клиент Telegram?

Нет. LinkiGram — независимый открытый проект на основе официального исходного кода Telegram для Android. Проект не связан с Telegram Messenger Inc. и не одобрен этой компанией.

Безопасно ли устанавливать APK?

APK собирается из открытого исходного кода через GitHub Actions и подписывается ключом автора. Вы всегда можете проверить сборку и изменения в репозитории.

Как обновляться?

Скачивайте новые версии с GitHub Releases и устанавливайте поверх текущей версии — данные не потеряются.

Какие архитектуры поддерживаются?

Единый standalone APK поддерживает ARM64 и ARMv7. Требуется Android 7.0 или новее.
